# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/11B9fjbym-TN7K-4TnrZ5MkAB9Ui3Ak1f

## Run Locally

**Prerequisites:**  Node.js

<img width="1403" height="838" alt="image" src="https://github.com/user-attachments/assets/219f03a4-de34-4834-aa62-2307a7a75fc5" />

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
